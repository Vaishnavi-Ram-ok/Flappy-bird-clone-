# 🐦 Flappy Bird Clone

A browser-based **Flappy Bird clone** built using **HTML, CSS, and JavaScript** as part of **Glee**, a college-level competition.

The project recreates the classic Flappy Bird gameplay with a simple, interactive interface where players control a bird, navigate through obstacles, and try to achieve the highest possible score.

🏆 **Competition Achievement:** Won a prize at **Glee**, a college competition.

## 🎮 Features

* 🐦 Bird movement and gravity-based physics
* 🟩 Randomly generated pipe obstacles
* 💥 Collision detection
* 📊 Real-time score tracking
* 🔄 Game restart functionality
* 🎨 Custom HTML & CSS-based game interface
* ⚡ Interactive gameplay using JavaScript

## 🛠️ Technologies Used

* **HTML5** – Game structure and elements
* **CSS3** – Styling and visual design
* **JavaScript** – Game logic, movement, collision detection, scoring, and interactions

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/flappy-bird-clone.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Start playing! 🎮

This project was developed for **Glee**, a college competition, where it received the third prize as part of the competition.

The project gave us hands-on experience in building an interactive browser game from scratch and applying JavaScript concepts such as **event handling, game loops, collision detection, DOM manipulation, and dynamic gameplay mechanics**.

* Built from scratch using vanilla **HTML, CSS, and JavaScript**
